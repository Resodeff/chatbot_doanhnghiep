1 - Cách vào venv [tại thư mục webs] (tạo thư mục mới nuế chưa có rồi đưa 2 forder dự án vào):
	venv\Scripts\activate.bat

2 - Cách dùng file setup.ps1
	.Công dụng:
		1. migrate – tạo bảng trong DB
		2. ensure_admin – tạo tài khoản admin
		3. import_linhkien --dir data – nạp dữ liệu linh kiện
		4. runserver – chạy web
	.Dùng khi:
		Vừa xóa db.sqlite3
		Chuyển dự án sang máy khác

3 - Cách mở server và API [kích hoạt API trước]:
	.API:
		uvicorn main:app --port 8001 --reload
	.Server:
		python manage.py runserver
